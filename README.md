# Cricketorium
This is an application to enter ball-to-ball information of a match. This is also called an Over Counter.
# Procedure
1. Select the 1st Batsman and the 2nd Batsman in the dropdown boxes given in top-right side.
2. Select the Bowler name near the Batsmen dropdown boxes.
3. You can wicket a person by selecting in the wicket-entering buttons (Bowled, LBW..., Retired).
4. You can add runs to a ball by clicking the runs-entering buttons (0, 1, 2, 3..., 7) below the wicket-entering buttons.
5. You can give extras by selecting the extras-entering buttons (Wide & No Ball).
6. When you wicket a batsman, the program shows you a pop-up showing that the current batsman was out by the type of wicket that you selected, like 'Bharathi Kannan is out by Catch'.
7. When the over is completed, another pop-up will open showing, like 'Over 1 completed!', 'Over Runs: 10' & 'Total Runs: 10', and ask for the next bowler.
